# CoopConnect — Cooperative Development & Funding Portal

[![CoopConnect live homepage](https://raw.githubusercontent.com/Kelvinkingly/Kelvinkingly/main/assets/coopconnect-homepage.jpg)](https://coopconnect-knowedge.infinityfreeapp.com/)

[Visit live website](https://coopconnect-knowedge.infinityfreeapp.com/)

An independent WordPress portfolio platform by KnowEdge Business Development Services Ltd. Features searchable grant and resource directories, editable development programmes, member interest preview, quarterly reporting with interactive sample KPIs and CSV export, and a responsive premium indigo-and-amber design.

Funding opportunities and dashboard data are illustrative only. No real grant, membership, or financial applications are accepted.

## Installation

Zip the theme/coopconnect directory, preserving its top-level folder. Upload via WordPress Appearance → Themes, then activate it. Sample records are seeded once.
